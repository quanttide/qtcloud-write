# 量潮写作云 - 业务需求文档

## 场景：内部转对外

### 工作角色

- CEO 助理：需要对外宣发品牌内容
- CEO：产出内部随笔和思考
- 系统：拆解叙事结构，辅助理解

### 问题

- 触发：CEO 发表了内部文章，助理需要改写成对外品牌故事或宣传册。
- 现状：CEO 的叙事风格独特，有自己一贯的推演逻辑。助理想模仿但不得要领，写出来总被说"不像他"。直接转发内部内容太生硬，从零重写又把握不住核心论点，反复修改耗时耗力。
- 困难：助理不了解 CEO 的思维方式——他只看到结果（写了什么），看不到过程（为什么这样写）。没有方法论支撑，每次改写都是一次性的猜测，无法积累对 CEO 叙事风格的理解。
- 后果：宣发效率低，对外内容与 CEO 本人的表达风格脱节。CEO 花大量时间改稿，助理得不到成长，品牌表达难以保持一致。

### 假设

如果存在这样一个平台，能够自动拆解 CEO 文章的叙事结构，让助理先理解他的推演方式，再在改写时对照参考、积累风格认知，助理就能写出"像他"的对外内容，且越用越顺手。
