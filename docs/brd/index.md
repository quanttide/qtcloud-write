# 量潮写作云 - 业务需求文档

## 场景：内部转对外

### 工作角色

- CEO：产出内部随笔和思考，也是产品的第一位用户——通过分析自己的文章看见叙事方式
- CEO 助理：需要对外宣发品牌内容，逐步内化 CEO 的叙事方法
- 新成员：需要快速上手，继承团队已有的风格认知
- 系统：组织叙事风格的基础设施，持续追踪、沉淀、传递

### 问题

- 触发：CEO 发表了内部文章，助理需要改写成对外品牌故事或宣传册。
- 现状：CEO 的叙事风格独特，有自己一贯的推演逻辑。助理想模仿但不得要领，写出来总被说"不像他"。直接转发太生硬，从零重写把握不住核心论点，反复修改耗时耗力。
- 困难：助理不了解 CEO 的思维方式——他只看到结果（写了什么），看不到过程（为什么这样写）。没有方法论支撑，每次改写都是一次性的猜测。即便一个助理学会了，新人来了还得从头再来；CEO 自己的风格也在演化，半年前的模式未必适用当前。
- 后果：宣发效率低，对外内容与 CEO 本人的表达风格脱节。CEO 花大量时间改稿。人员流动导致风格知识断裂，团队无法形成一致的品牌叙事能力。

### 假设

如果存在这样一个平台，能够自动拆解 CEO 文章的叙事结构、持续追踪风格变化、沉淀为团队可继承的方法库，让每个成员都能理解、内化、传递，团队就能建立持久的叙事一致性。
