# 量潮写作云 - 业务需求文档

## 场景：内部转对外

### 工作角色

- CEO：产出内部随笔和思考
- CEO 助理：需要对外宣发品牌内容
- 新成员：需要继承团队已有的风格认知
- 系统：组织叙事基础设施

### 问题

- 触发：CEO 发表了内部文章，助理需要改写成对外品牌故事或宣传册。
- 现状：CEO 的叙事方式不可见。不是助理一个人看不懂——CEO 自己也说不清自己是怎么写的。他的推演逻辑、习惯手法、结构模式，全部隐身在文章内容之下。每个人读到的都是"写了什么"，没人看到"为什么这样写"。
- 困难：看不见就没法教、没法学、没法传。助理靠猜改写，猜对了是一篇稿子，猜不对反复改。一个助理学会了，下一任从零来。CEO 自己的风格在悄悄变，但除了他自己没人察觉。等他意识到团队还在用半年前的方法库，已经脱节了。
- 后果：CEO 本人成了团队叙事一致性的唯一保障——每篇稿子都要他审、他改、他讲。写稿的人和管组织的人，角色完全重合了。这个局面不可能随着团队扩张而持续。

### 假设

如果存在这样一个平台，能让 CEO 的叙事方式变得可见——不仅对自己可见，也对每一任助理可见，随他的思考演化而更新——团队就能建立一种不依赖特定个人的叙事一致性。
