# 量潮写作云 - 产品需求文档

## 用户故事

### 灵感收集

作为写作者，我希望能够随时随地记录灵感碎片，这样我就不会因为无法立即写作而丢失灵感。

**验收标准：**
- 支持快速记录灵感，不打断当前活动
- 支持多种格式（文字、标签、引用等）
- 自动记录时间，保留上下文

### 灵感管理

作为写作者，我希望能够把灵感按照某种方式组织关联，这样我就能够建立自己的素材库。

**验收标准：**
- 支持为灵感打标签
- 支持建立灵感之间的关联
- 支持搜索和筛选灵感

### 灵感激活

作为写作者，我希望能够根据当前创作主题获得灵感推荐，这样我就能够快速进入创作状态。

**验收标准：**
- 能够分析当前创作主题
- 能够从素材库中推荐相关灵感
- 能够显示灵感与主题的关联度

### 创作扩展

作为写作者，我希望能够把灵感素材扩展成完整的文章，这样我就能够流畅创作。

**验收标准：**
- 支持基于灵感生成大纲
- 支持逐段扩展内容
- 支持AI辅助但保留创作主权
