# 量潮写作云 - 产品需求文档

## 主线故事

小陈是 CEO 助理，老板在内部发了一篇关于产品理念的随笔，小陈要把它改写成对外公众号文章。

他把文章粘贴到写作云，系统自动拆解出叙事结构。小陈一边看一边想：原来老板是这样推演的。

他关掉分析面板，开始动笔改写。把第一人称的自问自答转为第三人称的客户价值叙述，写到竞品部分卡住了——他翻出分析结果，对照笔记里老板惯用的类比方式，调整了一版。

两小时后，宣发稿定稿。老板只改了两处措辞，说："这次路子对了。"

## 用户需求

### 叙事分析

作为 CEO 助理，我希望把 CEO 的内部文章导入系统，系统自动拆解出叙事结构，这样我就能理解他的推演方式。

**验收标准：**
- 支持粘贴或上传 CEO 的原始文章
- 自动识别文章的叙事单元（起承转合等）
- 展示每个单元的逻辑功能：叙事动作、严密性支撑、逻辑效果
- 原文按段落切块，分析结果与原文段落对应排列

### 对照改写

作为 CEO 助理，我希望在动笔改写时对照分析结果，这样我就能保持 CEO 的核心叙事逻辑，而不是从零开始。

**验收标准：**
- 分析面板可展开/收起，不干扰写作
- 支持在分析结果上做笔记标注
- 改写时能快速定位到原文的对应段落

### 风格积累

作为 CEO 助理，我希望系统能积累多篇文章的分析，逐渐勾勒出 CEO 一贯的叙事风格，这样我就能越用越顺手，不再每次从零学起。

**验收标准：**
- 每篇文章的分析结果可存档
- 支持跨文章对比叙事结构异同
- 自动提炼高频叙事手法
