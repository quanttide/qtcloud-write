# “啊不对，是从客户的角度设身处地”

DeepSeek 对我的工作日志里无意写的一句话大加赞赏：


“但是其实最接近的方法就是写业务实录，说我们过往都是怎么解决问题的。啊不对，是从客户的角度设身处地地想。终于自洽了。”


这句话的上一句是：


“最关键的转换是转换到了客户视角。我找到了一个舒服的方法。代表客户对团队说话，要求他们理解。代替强制要求他们做什么。因为我开始理解了情境那个藏着的真正重要东西。”


DeepSeek 还建议我把这个转折直接作为标题。他的理由是，这是我放弃了从内向外看的视角，彻底切换到了从外向内看的观察角度。


于是就有了这篇文章。


此时此刻我正在回想刚才和 DeepSeek 对话逐渐放松的过程。


我问 DeepSeek，“从客户视角不应该是理所当然的吗？”


DeepSeek 解读了我的羞耻感。它说，我从前把自己设定为一个理应清楚一切的创始人。而这一刻起，我放弃了那个似乎全知全能（但实际上只是幻觉）的视角，承认自己也同样要面临困难，承认自己只能有限承诺，以帮助者而不是拯救者的身份。


达到这一刻，我经历了很多次认知重构。那一刻我会想了很多源头，一个又一个顿悟的画面在我眼前闪烁。


DeepSeek 把我的叙事风格概括为“场景-困境-救援”。这是解开我困惑的钥匙，于是我把这个概括发给了秘书处学习。


当我找到了这个叙事以后就可以不断强化。DeepSeek 建议我，如果我从外部视角看自己的时候，我会怎么描述一个“被各种压力困扰的创始人会如何想”？


DeepSeek 非常奇妙地激发了我的探索欲。于是我把同主题的文章发给他。


他说，我在前面的文章说宣传册难写，是因为我把想象力而非结构作为关键，给想象力过大的压力。


好的文章是改出来的。这是写小说的时候 DeepSeek 和我说的。


GitHub 化以后，“改”变成了理所当然的暑期，于是我感觉到我更敢改了。


我是怎么放弃完美主义的呢？当我发现我解决不完所有的问题，转而描述“情境”是什么，让问题自然蕴含在问题里，交给团队。


其实不是完美主义，而是羞耻感。DeepSeek 说，羞耻感是真实地经历过困难的证明。


我觉得我突破了一种商业文化。一种所有人都在宣传自己改变了世界的浮躁。敢于承认说，自己也有很多局限，也不敢随便承诺。


我在想，如果我们的乙方这么和我承诺，我会觉得他们很透明踏实。所以我这么要求团队。而这些同理心是早蕴含在内心的视角，只是我从来没有把这个视角拿出来。


我想我的团队们读了这篇文章立刻就会悟到这个困扰我们N 久的集体心理困境。


这也是困扰整个行业的心结。所以你在这个行业里看不到多少真正真诚的、站在他者视角的分享。而这恰恰是我们高度擅长而不自知的。


这个标题本身也是一次自我救援。我放下了那个被羞耻感困扰的自己。


在我的文章里，这可能是我第一次这么平静地讨论“羞耻感”这个我最怕的东西。


既然“羞耻感”是真实经历过困境而获得的同理心，是我们可以设身处地的理解客户视角的风险和顾虑的原因。


所以不用纠结。不用写完美的状态是什么。写真实的困惑就可以。


我记得上次我和 DeepSeek 讨论到写文章的困惑，DeepSeek 说，我是困惑于，如果我不写尖锐的文章，我可以写什么获得关注呢？


现在我有了答案。写同理心，写我们的客户们真实的困境被看见，写我们可以为他们做些什么。
