# 札记

通过推演来理清认知的文章。推演对象可以是作者自己的认知缺口，也可以是外部现象或问题。

## 模型：三级抽象

所有札记都从具体层出发，经过渡到达本质层，再推演到应用层。

```
具体层 ──过渡──→ 本质层 ──推演──→ 应用层
```

## 维度

**具体层的呈现方式**

起点可以是认知缺口（作者自己的困惑），也可以是待分析的外部现象。

| 文章 | 起点类型 | 起点 |
|------|---------|------|
| a1 | 认知缺口 | 不知道自己在做什么的僵局 |
| a2 | 认知缺口 | 昨天还在想，今天就发现白干了 |
| a3 | 认知缺口 | DeepSeek 对无意句子的赞赏 |
| a5 | 认知缺口 | 网络环境可信任程度持续降低 |
| bad1 | 外部现象 | 千问送20亿奶茶做裂变活动 |
| bad3 | 外部现象 | 培训机构用饥饿营销欺骗学员 |
| bad5 | 外部现象 | 甲方随意变更需求影响协作 |
| bad6 | 外部现象 | AI 成为面试"提词器" |

物质锚点：具体层一定有实物做支点。

| 文章 | 锚点 |
|------|------|
| a1 | 战棋游戏、代码仓库 |
| a2 | 助理小周的原话 |
| a3 | 工作日志句子、DeepSeek 点评 |
| a5 | 交友软件、微博、小红书、短剧 |
| bad1 | 千问奶茶券活动数据 |
| bad3 | 竞品营销套路、学员调研 |
| bad5 | 甲方变更需求的真实场景 |
| bad6 | 面试间 AI 代答场景 |

**从具体到本质的过渡**

强制桥接：跨越具体层到本质层时有显式桥梁。

| 文章 | 桥梁 |
|------|------|
| a1 | 游戏可玩性 = 机制 + 意义 → 产品智能感 = 交互 + 价值 |
| a2 | 写作自动化 → 看清自己 → 卸下负担 |
| a3 | 自我纠正 → 放弃全知视角（DeepSeek 解读） |
| a5 | 环境变差 → 情绪卷入 → 本质是模糊试探 → 需要新契约 |
| bad1 | 奶茶券数据 → CAC/LTV 分析 → 裂变活动本质判断 |
| bad3 | 营销套路分析 → 教育作为信任品 → 议事型课堂价值 |
| bad5 | 变更需求场景 → 契约与信任 → 共赢协作模型 |
| bad6 | AI 代答现象 → 培训行业异化 → 招聘公平的底层问题 |

**结构的完整性**

首尾咬合：结尾回到开头，或收束到结论。

| 文章 | 开头 → 结尾 |
|------|-------------|
| a1 | 不知道做什么 → 研发异常顺利 |
| a2 | 白干了 → 看清了路 |
| a3 | 无意识句子 → 写真实的困惑 |
| a5 | 环境信任下降 → 需要新社会契约（开放收束，非闭环） |
| bad1 | 千问奶茶活动火不火 → 用 CAC/LTV 看透活动本质 |
| bad3 | 竞品用饥饿营销 → 回归教育是信任品的本质 |
| bad5 | 甲方随意改需求 → 契约与信任框架 |
| bad6 | AI 代答毁招聘公平 → 回归真实能力考察 |

## 已验证

三篇作者视角文章验证，四篇分析视角文章加入，三级抽象模型覆盖两种起点类型。
