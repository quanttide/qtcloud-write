# 宣传册风格

企业宣传册不属于"札记"（读者理清认知），也不属于"故事"（读者感受态度），而是一类独立的实用文体，其叙事意图是让读者**被说服决策**。

## 模型：阶段×视角矩阵

宣传册的结构风格由一个二维矩阵定义：

- 行（阶段）：调研洞察 → 策略定位 → 信息架构 → 内容与设计 → 生产分发 → 评估迭代
- 列（视角）：老板、销售、技术、客户、设计

每一阶段每一视角都有必须满足的结构要求。宣传册的结构质量由矩阵中所有格子是否被满足来判断。

## 维度

### 阶段递进

每一阶段必须完成本阶段的所有视角要求，才能进入下一阶段：

| 阶段 | 核心结构要求 |
|:-----|:------------|
| 调研 | 收集老板的战略目标、销售的客户问题、技术的关键优势、客户的真实痛点、执行的预算节点 |
| 策略 | 凝练成一句核心信息，明确调性，锁定销售工具清单 |
| 信息架构 | 设计"痛点→方案→优势→行动"的主逻辑，规划每页信息优先级 |
| 内容与设计 | 所有信息落地，案例有真实数据，页面有留白和视觉节奏，行动呼吁清晰 |
| 生产分发 | 印刷数量、渠道、电子版、销售分发方式全部确定 |
| 评估迭代 | 设定收回反馈的机制，记录修订单 |

### 视角对齐

每一阶段必须同时回答五个视角的关切：

| 视角 | 核心关切 |
|:-----|:---------|
| 老板 | 品牌形象是否高端？战略目标是否传达？ |
| 销售 | 是否有案例页、对比页、FAQ、扫码跟进工具？ |
| 技术 | 技术优势是否准确且通俗？ |
| 客户 | 痛点是否被理解？方案是否可信？下一步做什么？ |
| 设计 | 信息密度是否可执行？版式是否统一？ |

### 结构完整性

- 首尾咬合：开篇的客户痛点，必须在方案和案例中被回应，最终以行动呼吁收束
- 锚点不虚：每一阶段必须有物质锚点（客户原话、真实数据、已有素材），不允许空泛概括
- 过渡显式：阶段转换必须有明确桥梁（如"基于以上洞察，我们决定……"）

## 检验方式

使用矩阵作为检查清单：逐阶段、逐视角检查每个格子的要求是否被满足。全部"是"则结构风格合格，任一"否"则返工对应内容。

## 与表达风格的关系

本定义仅针对结构风格（信息组织逻辑、阶段推进、多角色对齐）。表达风格（语气、人称、措辞、节奏）是另一个维度，需单独制定指南。结构风格先于表达风格验收：结构不通过，不值得谈表达。
