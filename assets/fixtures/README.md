# 测试样例

按叙事风格（读者获得）组织：

## style/：各风格定义

- `index.md`：分类标准入口，三种风格速览
- `essay.md`：札记——读者理清认知
- `story.md`：故事——读者感受态度
- `brochure.md`：宣传册——读者被说服决策

## content/：文章按风格分类

- `essay/`：札记
  - good1：构建游戏启发了我的产品设计理念
  - good2：第二大脑的意义在于卸下认知负担
  - good3："啊不对，是从客户的角度设身处地"
  - good5：性别对立的环境需要更透明的交友契约
  - bad1：千问送20亿奶茶，是"自嗨"还是"赢麻了"？
  - bad3：真正好的课程，从来不用饥饿营销绑架信任
  - bad5：别让"随意改需求"，打乱共赢的节奏
  - bad6：当AI成为面试"提词器"
- `story/`：故事
  - good4：一时拒绝一时爽，一直拒绝一直爽
  - bad4：从焦虑到胜任：我的大数据学习之旅
- `brochure/`：宣传册
  - bad2：这门课给你一把解决复杂问题的万能钥匙

每条文章附带 `_review.md` 分析其是否符合对应风格。
