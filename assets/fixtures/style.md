# 叙事风格

## 模型

作者的叙事风格内核是**三级抽象**：所有文章都从具体层出发，经过渡到达本质层，再推演到应用层。其余手法都是三级抽象在不同维度上的实现。

```
具体层 ──过渡──→ 本质层 ──推演──→ 应用层
```

## 维度

### 具体层的呈现方式

**困难前置**：具体层以一个认知缺口为起点。可以直接亮出（"我不知道做什么"），也可以在对话中逐渐揭示（"羞耻感"）。

| 文章 | 起点 | 类型 |
|------|------|------|
| a1 | 不知道自己在做什么的僵局 | 直接 |
| a2 | 昨天还在想，今天就发现白干了 | 直接 |
| a3 | DeepSeek 对无意句子的大加赞赏 | 揭示 |

**物质锚点**：具体层一定有实物做支点，不空谈。

| 文章 | 锚点 |
|------|------|
| a1 | 战棋游戏、代码仓库 |
| a2 | 助理小周的原话、例句 |
| a3 | 工作日志句子、DeepSeek 点评 |

### 从具体到本质的过渡

**强制桥接**：跨越具体层到本质层时一定有显式桥梁。作者可以自己搭建，也可以借助对话伙伴。

| 文章 | 过渡路径 | 建桥者 |
|------|----------|--------|
| a1 | 游戏机制 → 产品智能感（同构等式） | 作者 |
| a2 | 写作自动化 → 认知解放（因果链） | 作者 |
| a3 | "啊不对" → 放弃全知视角（DeepSeek 解读） | DeepSeek |

### 结构的完整性

**首尾咬合**：结尾一定回到开头，形成闭环。

| 文章 | 开头 | 结尾 |
|------|------|------|
| a1 | 不知道做什么 | 研发异常顺利 |
| a2 | 白干了 | 看清了路 |
| a3 | 一句自己没意识到的句子 | 写真实的困惑就可以 |

## 待验证

article3 的叙事由对话交替驱动（作者是"被揭示者"而非"解谜者"），前两篇不依赖这个机制。这是第三种变体还是独立的手法？需要更多样本判断。
