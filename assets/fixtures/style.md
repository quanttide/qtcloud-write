# 叙事风格

该 CEO 的叙事风格核心特征是**诚实面对认知缺口，用物质锚点搭建抽象阶梯，从不跳跃也不留断层**。目前基于两篇文章归纳出五种高频手法：

### 困难前置

先展示认知缺口，再展示解法路径。

- article1：开篇承认"不知道自己在做什么"
- article2：开篇承认"昨天还在想，今天就发现白干了"

信任建立在"这个人诚实面对困难"之上，而非"这个人很厉害"。

### 物质锚点

每层抽象都有具体事物作为支点。

- article1：战棋游戏、模拟经营游戏、qtgame-war、qtadmin
- article2：助理小周的原话、"这个其实没有什么难的"例句

抽象可信度来自实物证据，而非作者的判断力。

### 强制桥接

跨界跳跃时一定显式搭建逻辑桥梁。

- article1：游戏可玩性 = 机制反馈 + 意义感 → 产品智能感 = 交互反馈 + 价值感
- article2：写作流程产出好文章 → 看清自己 → 卸下负担 → 定义认知基础设施

读者不会觉得跳跃，而是被牵引着走完每一个逻辑台阶。

### 三级抽象（具体→本质→推演）

从不跳过中间层。

- article1：具体困境 → 抽象建模 → 流水线转化 → 团队未来工作方式
- article2：助理的突破 → 认知解放 → 认知基础设施定义 → 未来组织形态

### 首尾咬合

结尾一定回到开头提出的问题。

- article1：开头"不知道做什么" ↔ 结尾"研发异常顺利"
- article2：开头"白干了" ↔ 结尾"看清了自己的路"
