# 量潮创始人实验室 — 概念验证清单

面向写作云（qtcloud-write）的逐项验证序列。

## 分组 & 依赖关系

```
元模型层 — 叙事工程实验室（examples/default/）
│
P3 — 模型驱动验证
└── p04 范畴模型驱动的写作工作台    依赖：meta/（contract.yaml + Lean 模型）

分析层 — src/provider
│
P4 — 闭环验证
├── p03 评审标注嵌入编辑器          依赖：p02（复用 UI 模式）、provider API
└── p05 多文档风格对比             依赖：provider（StyleStore）

编辑层 — src/studio / write-agent-studio
│
P1-P2 — 基础验证
├── p01 写作云 3R 引擎             依赖：无（独立验证）
└── p02 写作云 HTML 原型           依赖：p01（复用 3R 方法论）
```

## PoC 清单

| # | PoC | 验证目标 | 验收标准 |
|---|-----|---------|---------|
| 1 | 写作云 3R 引擎 | 创作情境引导核心模式有效：在已有文本中发现空隙，引导作者进入未写场景 | 空隙检测可用、情境引导可操作、3R 循环可追踪 |
| 2 | 写作云 HTML 原型 | 在投入 Flutter 之前验证三栏布局 + 3R 循环的桌面交互体验 | 三栏布局、Markdown 编辑、评审面板、情境引导、3R 仪表盘、状态栏六项可运行 |
| 3 | 评审标注嵌入编辑器 | 把 provider 分析结果嵌入编辑器，形成"写作→评审→修改→再评审"闭环 | 空隙标记、叙事标签、侧面板分析、点击跳转、一键重评 |
| 4 | 范畴模型驱动的写作工作台 | 用 contract.yaml FSM 约束实际写作行为，验证阶段转换的合法性 | 阶段显示、合法态射过滤、自环计数器、非法操作提示、转换记录 |
| 5 | 多文档风格对比 | 可视化对比多篇文章的叙事结构分布，发现作者的写作模式 | 分布热力图、偏差可视化、段落对比对、筛选过滤、趋势图 |

## 推荐实施顺序

| 优先级 | PoC | 预估工作量 | 状态 |
|--------|-----|-----------|------|
| 1 | p01 写作云 3R 引擎 | 小 | 已实现 |

| 3 | p03 评审标注嵌入编辑器 | 中 | 待实现 |
| 4 | p04 范畴模型驱动的写作工作台 | 中 | 待实现 |

## 技术栈

| 层 | 推荐选择 |
|----|---------|
| 写作引擎 | Python 3 CLI（p01） |
| 界面原型 | 单 HTML 文件（p02/p03/p05） |
| 工作流引擎 | Rust + Lean（p04） |
| 版本控制 | Git（内置） |
| 文档 | MyST Markdown |
