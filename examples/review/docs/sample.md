# 宣传册检查表

这个矩阵把 行（纵向） 设为工作流阶段（时间线），列（横向） 设为利益相关者视角（谁在决策/谁受影响）。每个交叉点是一个需要回答的问题或必须满足的条件。

—

矩阵结构

工作流阶段（行） \ 利益相关者（列） 老板/高层 销售部门 技术/产品 客户 设计/执行
1. 调研与洞察 册子要达到什么战略目标？（品牌升级？获客？融资？） 客户常问哪些问题？哪些竞品册子在抢单？ 有哪些必讲的技术优势？容易误解的点是什么？ 客户最痛的三个场景是什么？决策顾虑有哪些？ 预算范围？已有素材可用性？时间节点？
2. 策略与定位 核心信息一句话：“我们是谁 + 凭什么信 + 你要做什么” 册子必须包含的销售工具清单（对比页、案例索引、FAQ） 技术门槛如何通俗化？可否用图示？ 册子调性：专业？亲民？高端？ 版式基本方向（A4？方册？横版？）
3. 信息架构 品牌信息是否前置且有层级？ 案例和产品页是否便于快速查找？ 技术信息是否准确且无夸大？ 痛点→方案→优势→行动的逻辑通畅吗？ 每页信息密度合理吗？留白和视觉节奏？
4. 内容与设计 品牌色、logo、关键照片是否符合VI？ 有无可扫码的销售跟进页？有无话术配合页？ 产品参数、原理图、认证证书是否准确？ 文案是否戳中痛点？案例是否真实可信？ 出血、字体、图片分辨率、印刷工艺明确？
5. 生产与分发 印刷数量、渠道匹配预算？电子版如何传播？ 销售每人得到几本？展会如何发放？电子版如何分享？ 技术部门是否需要电子版发给客户？ 客户在什么场景拿到册子？方便带走吗？ 打样、校对、印刷周期、运输安排
6. 评估与迭代 册子带来的线索量或品牌调研得分？ 销售反馈：册子是否帮他们签单？常用哪些页？ 技术部门收到客户哪些关于册子的提问？ 是否有客户主动扫码或打电话？满意度？ 修订单记录，下次印刷改进项

—

使用说明

1. 填表方式：每个单元格写出一句话要求或一个待解决的问题。例如老板/高层 + 调研洞察：“提升企业在工业客户中的专业形象，支撑下一轮融资”。
2. 优先级：不必一开始填满所有格子。建议先填 客户列 和 老板列，再填销售和技术，最后填设计。客户决定册子是否被读，老板决定是否批准，销售和技术提供素材，设计执行。
3. 复盘检查：当某一行的五个格子都填完后，检查是否存在矛盾（例如老板要高端黑卡风格，客户要亲民读得懂——这时需要调和）。
4. 动态更新：随着项目推进，每进入一个新阶段，可以把上一阶段填的内容刷新一遍。
