# InspirER 开发文档

## 概述

InspirER（Inspiration ER）是一个基于个人创作日记的灵感启发工具。

核心价值：**它比你更记得你以前是怎么思考的。**

当你在2026年写下"男主很痛苦"时，它能瞬间帮你找回2024年关于"痛苦情绪描写"的灵感片段。

---

## 架构设计

### 核心流程

```
读取日记 → 提取主题 → 查找相关记录 → 生成建议
```

### 核心类

```
Inspir
├── load()              # 加载日记
├── extract_themes()    # 提取主题标签
├── find_related_entries()  # 查找相关记录
├── suggest()           # 生成建议
└── generate_suggestion()  # 生成建议文本
```

---

## 数据结构

### 输入：archive.md

```markdown
# 日志

## 2026-04-15
今天想重写便利店谈心。
...

## 2026-04-14
今天是如何进入创作状态的？
...
```

### 解析结果

```python
{
    "date": "2026-04-15",
    "content": ["今天想重写便利店谈心。", ...]
}
```

## 主题提取

### 支持的主题

| 主题 | 关键词 |
|------|--------|
| 创作 | 创作、写 |
| 灵感 | 灵感 |
| 人物 | 男女、男主、女主 |
| 情绪 | 情绪、心情 |
| 重写 | 重写 |

### 实现方式

基于关键词匹配的规则系统（Rule-based NLP）。

---

## 相关记录查找

### 逻辑

1. 从最新日记提取主题
2. 在历史记录中查找包含相同主题的记录
3. 返回相关记录（默认3条）

---

## 建议生成

### 预设建议

| 主题 | 建议 |
|------|------|
| 创作 | 可以参考过去的创作状态，调整当前创作节奏 |
| 灵感 | 这些片段可能触发新的灵感火花 |
| 人物 | 可以进一步发展这些人物关系 |
| 情绪 | 这种情绪状态值得在作品中表达 |
| 重写 | 这是一个重写旧作的好时机 |

---

## 演进方向

### 当前版本

- 关键词匹配
- 静态建议

### 下一步

- 语义检索（embedding）
- LLM 生成建议

### 最终目标

**基于个人记忆的语义联想引擎**

- 自动回忆相似状态
- 自动触发过去经验
- 构建创作上下文连续性
