# ROADMAP — 写作云 Studio

## 目标

验证 **"AI 原生写作编辑器"**：写作全程（收集 → 分组 → 初稿 → 定稿）AI 只做组织、不改写原文，
人在环中做取舍决策。编辑器与 CLI 四命令共享同一数据目录（journal/ groups/ materials/）。

## 当前状态

已移植 qtfounder 新版写作编辑器（丢弃 3R 评审工作台），并复现 CLI 四命令流程：

- [x] 三栏编辑器：章节阶段树 + 纯文本编辑区 + 只读标注层 + AI 整理面板
- [x] AI 只产元数据：`.analysis/` 缓存删除即还原，原文零改动
- [x] 分阶段分析：01_收集 灵感分解；其他阶段 结构分析
- [x] 负反馈（忽略的建议不再提出）+ 分析缓存 + 强制刷新
- [x] 自动保存（3s 防抖）、字数统计、脏标记
- [x] 四阶段工作流对齐 CLI 四命令产物目录
- [x] **客户端复现 CLI 四命令**：流程操作面板执行 collect/organize/distill/express
      （`lib/workflow/` 为 CLI 逻辑的 Dart 移植，提示词与产物格式一致）
- [x] 38 单元测试 + 1 真实 LLM 集成测试（无 key 自动跳过）
