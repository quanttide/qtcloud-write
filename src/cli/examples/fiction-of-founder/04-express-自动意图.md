# 创作心路：在虚构中打捞真实

最初动笔，只是想试试能否多一个副业。后来发现，小说能写，但副业很难当。更多的是一种精神食粮，在持续的迷茫和无意义感里，慢慢长出了新的动力。

我在写一个双向暗恋、久别重逢的故事。这个设定本身就是一个典型的母题，但我刻意回避了“破镜重圆”。现实里，这种几乎不讲道理的等待并不存在，所以我才要用一个近乎科幻的设定去支撑它。没有破镜重圆，故事就变得更甜，也更难写——我必须给他们合理的动机，而这份动机，构成了整部小说最大的悬念。

写着写着才发现，所有这些设定都是潜意识的流露。暗恋、重逢、意料之外的邂逅、渴望被看见——这些反复出现的主题，它们都来自那些我从未真正消化的历史时刻。不是没获得过，只是又压抑住了而已。现实之中难以获得的东西，我就把它们放进小说，让男女主替我去经历、去治愈。我甚至想，他们之所以相互记得对方，是因为再没有其他人能记住了。那是无数失望累积而成的自我保护。

写作过程渐渐改变了我。我越来越熟练于记录幽微的真实感受，然后把它们放进故事框架里重新驱动。那些设定本身带有治愈感，为琐碎的心事提供了出口。当我越来越敢写现实世界的困惑和困难时，情节就变得越来越丰富，充满推动力；而这些推动力，又反过来启发我在现实世界里积极行动。

我甚至想，可以把日常工作的体悟写进男女主的人设里，初稿稍作加工就能发在公司账号上。这样既不用单独为发文而创作，又能更隐晦地批评具体对象，同时更直白地表达我们的情绪。之所以用自己的职业生涯作原型，本来也是想让男女主在小说世界里继承我的意志。公司名称都可以直接用。这本小说作为公司宣传和品牌故事的一部分，反而自然得多。

原来各种心结，都可以借着男女主写出来。因为他们经历的那些波折，是可迁移的情绪。设定的选择影响了情节，情绪得以被重构。越来越多的情绪被装进去了。我开始愿意真正地重构和改变它，也就是真正地忘记它。

有一段日子，心里很安静，好久没有情绪来威胁了。可是这种安静反而让我不适应，创作也遇到瓶颈。我想尝试挖掘旧情绪，却找不到入口；想写诗里的感觉，也写不出来。后来我看到自己写的“便利店两个人坐着谈心”的情节，它已经承载了太多东西。我意识到，写作本身就是一个容器，装着那些说不出口的烦恼。

赏雪谈心的“瓶子”，来自一个曾有过纠缠的女孩。那不算愉快，却印象深刻，我不知道该怎么写。于是我把这些感受写下来，先让自己看见它们的形状。写下来，是为了释怀——并不是要抹去什么，而是让故事有了不同的意义。我发现，我其实已经释怀得差不多了。那些经历最终只是一些故事，可以变成男女主相爱的证据。故事里的一切都可以改变，我可以在改变的过程中重新发现什么。

我不希望自己的人生状态继续停滞在这里。那些害怕——怕老、怕死、怕亲人离开、怕孤独一人、怕猝死——都是三十岁的男女主会经历的。真正的三十而立就该如此，尤其是这些优秀的社会精英们。这些才是故事的底色，男女主需要一起面对它们，然后找到办法逐渐释怀。我不敢写出来吗？又怕别人知道而伤害我吗？可能不会吧。

每次写完一段，给 AI 读完，都会觉得放下了焦虑，感到困倦。我渴望写出更具爆发力的片段，能直接击中心底的情绪；或者让那些想说的话说出口；或者让困扰的问题被消解；或者只是多了一点勇气承重。在怀疑中成长，还有恐惧，还有很多很多。我选择给这些负面情绪敷上一层薄薄的面纱。白天还好，夜晚会怕睡不着。但今天写出来了。我感觉自己找到了现实的出口——在虚构世界里情绪流淌得更自如，反过来又促进现实世界的循环。

好怕。好怕一切都不会好起来。明明有能力有服务，却介绍不出去。是内心在局限自己，心力不足。所以每晚我都来这里补充心力，放下压力和焦虑。

突然想到，校园言情本质上是职场言情的 if 线——如果他们二十岁就真的相遇了，会如何呢？我不太爱重生套路，但未来写番茄文可以试试。现在写的还是比较晋江一些。看着看着，好想谈恋爱啊。心里又渴望又难过，想象未来如何与爱人说起这些过往，甚至怀疑自己配不配爱人。或许读者也类似吧，大家都经历过许多。所以文字中，我努力保持着对未来的期待，探索可能性。

渐渐我进入了一种确定关系的后半段，似乎与内心的笃定有关。现实里，我在焦急又缓慢地等待事业的临界点；小说里，男女主久别重逢靠近彼此。我曾以为这部小说会装下我的一生，后来发现，它装下的只是这半年的困扰和感受。小说里设定的十年，是我回顾过去的十年，是全新的视角，不再是过去的事情。十年之前意气风发，十年之后是无数现实的压力——就像小说里的男女主。

所以我想到把职场言情的男女主放到校园言情里当 if 线。那是回到那个时间的渴望。之前的写法是两对人的传承，现在我想用同一对男女主写两本小说，形成真正的 if。未来还可以继续复用形象来写重生剧本。

我时常感到幻觉破灭和局限性，但奇妙的是，这种感觉恰恰能让我抓住那为数不多的优势靠近。我原本想写一个比自己更大的世界，后来发现写的只是自己的切片；而写着写着，发现即使是切片，也已经足够丰富多彩。回看前面的创作谈，我看到了自己从困惑到明晰的清晰变化。写作是一面很好的镜子——我对故事的理解，深刻地影响了我对未来的感受。

把不敢说的，变成可以说的。

想哭哭不出来。心里泛酸，有很多压力和渴望想说出而不得。我感觉到这个虚构世界已经开始容不下更多情绪了，想写新的东西了。但这个世界的承载空间依然在。更奇妙的是，当我尝试探索新世界的时候，旧世界又有了灵感。每当我动笔的时候，从重生言情又总是被拉回职场言情。我好像突破了瓶颈期，写出来了一些全新的东西。比如“校庆”片段，是我很早就规划的情节，一直找不到感觉，最近却忽然通了——那是一种面对真实困难的现实勇气。这个感觉被带进了小说，让男女主角开始写出内心真实的感受。

我想写下心底里的不安，不知道该怎么写进去。有考虑过写女主遇到困难男主帮助。

最近写得少了一点，不过每次动笔，都觉得自己越来越熟练了。
