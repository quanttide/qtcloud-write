# 写作疗愈：在虚构世界中安放真实

我一直在写一个双向暗恋、久别重逢的故事。这是一个典型的母题，但我刻意回避了“破镜重圆”这一常见设定，也因此让故事变得难写得多——我必须在没有旧伤复燃的前提下，给他们合理的理由重新靠近彼此。这份难度构成了整部小说最大的悬念，也让基调甜了许多。

在写作的过程中，我逐渐意识到，这个故事实际上是潜意识的窗口。我选择用男女配夫妇的视角来展示创作潜意识，让它成为作品的一部分，成为作品的底色。我审视自己最初的创作冲动——我为什么反复写邂逅、写一见倾心或久别重逢？因为这些是我心底最深处的渴望，是现实之中难以获得的东西。或者说，不是没获得过，只是又压抑住了而已。

“我们不需要回到过去，我们现在就可以重新认识一次。”这句话似乎是整部小说的灵魂，也是我对自己说的话。

写作时，我明显感到一种“理智落后于情感”的状态，让角色不断突破我预设的边界。我总是想写一些更深的、更不敢碰的主题，但这些主题在“双向暗恋”的设定下似乎无处安放。可后来我发现，即使刻意在设定上回避，那些没有消化的历史事件依然在隐隐约约地影响文本和当下。于是我开始尝试把那些情结背后的情绪写进小说里，让男女主去互相治愈，让情绪在故事框架下被重新驱动。

这个过程渐渐改变了我。我越来越熟练于记录真实的、幽微的感受，然后把它们放进故事里重新活一遍。故事设定的治愈感，为那些琐碎的、说不出口的事提供了出口。当我越来越敢写现实世界的困惑和困难时，情节反而越来越丰富，越来越充满推动力。而这些推动，又反过来启发我在现实世界中积极行动。两个世界成了一个互相滋养的循环。

我意识到，各种心结是可以通过角色写出来的。他们经历的那些波折，是可以迁移的情绪；设定影响了情节，让情绪可以被重构。越来越多的情绪被装进去了。我开始愿意真正地重构它们，也即真正与它们告别。

其实，关于这段故事的底色，有一个具体的来源——一个我定义为“瓶子”的形容，来自一个有过纠缠的女孩。这不是一段愉快的经历，但印象深刻。我把这些感受写下来，是首先让自己看到这些形状的样子。最初我不知道这和释怀有什么关系，也不知道这个原型和故事里的男女主有什么关系。后来我明白了：释怀是故事有了不同的意义，而我可以继续向前，而不是让情绪停留在原地，像那个时候的她一样。我看到了自己也曾经执念过，所以写下这段十年重逢，希望男女主可以满足他们的执念。

这句话好像打开了一扇门。很多积压的情绪从这扇门走了出来——关于心底最深处被看见的渴望，关于那些爱过的女孩，关于那些落空的想象。我不敢过多回想，是害怕那些落空的想象会再次让我难过。但大部分其实也忘了，留下一些印记变成现在的我。写着写着，我发现自己已经释怀得差不多了。释怀的是什么呢？是那些经历最终成了一部分故事，它们可以变成男女主相爱的证据；故事里的一切也都可以改变，我可以在改变的过程中重新发现什么。

这个虚构世界里，男女主背负着我的一部分人生。他们三十岁，会面对死亡焦虑、衰老恐惧、亲人离世的害怕、孤独一人的无措。这些是三十岁的成年人真正会经历的。真正的“三十而立”就应该是这样——即使是所谓的社会精英，也需要在光鲜表面之下面对这些真实的人生底色。男女主需要一起面对这些，然后找到办法逐渐释怀。我有时会问自己：我敢写出来这些吗？又害怕被别人知道而伤害自己吗？可能不会吧。

写作带来的不仅是表达，更是一种身体性的反应。每次写完一段并读出来，我都会觉得焦虑放下了，困倦感随之而来。我渴望写出更具爆发力的片段，能够直接击中心底的情绪。或者是让那些想说出口的话可以说出口，让那些困扰许久的问题被消解，又或者仅仅是多了一些勇气和习惯来承载更多的重量。与此同时也有怀疑，恐惧，还有在无数怀疑中成长。

“把不敢说的，变成可以说的。”这句话可以被视为整个写作过程的注脚。

有一天晚上我回想这一切，突然想到：校园言情本质上是职场言情的 if 线——如果他们二十岁时真的相遇了，会如何？我想回到那个时间的渴望，让我产生了这个想法。这部小说装下的并不是我的一生，而只是写作这半年的困扰和感受。但即便是切片，也已经足够丰富多彩。回看之前的创作谈，我能看到自己清晰的变化，从困惑逐渐到明晰。写作是一面很好的镜子——我对故事的理解深刻地影响了我对未来的感受。

写到后来，一种奇妙的循环发生了：当我觉得这个虚构世界已经容不下更多情绪，想要写新东西时，尝试探索新世界反而让旧世界又有了灵感。突破瓶颈后，我写出了之前规划了很久却一直找不到感觉的情节。比如“校庆”那个片段——它面对的是真实的困难，是一种现实的勇气。这种勇气进入了小说，让男女主开始写出他们内心真实的感受。

现在我还在写作的路上，动笔越来越熟练。写作疗愈对我而言，不是把伤口一遍遍揭开，而是给那些从未被言说的情绪一个栖身之所，让它们在故事的维度里被重新看见、重新安放。小说里的十年，是我回顾过去十年的全新视角；这种回顾的终点不再是原地踏步，而是带着所有那些被看见的情绪，继续向前走。
