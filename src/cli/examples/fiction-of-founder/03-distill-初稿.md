# 创作动机

写这部小说时，我刻意回避了“破镜重圆”，也刻意模糊了十年重逢里彼此是否还有过其他感情经历。从现实来看，这种近乎不讲道理的等待几乎不存在，我却刻意采用了这个科幻般的设定。网文小说的基本特点之一就是幻想设定，一类母题往往体现一类集体潜意识。“双向暗恋、久别重逢”正是这样一个典型的母题。我的选择是其中比较小众的分支：没有破镜重圆，把基调调甜，却也因此难写得多——因为这个设定要求我为他们的等待给出合理的动机，而这恰恰构成了整部小说最大的悬念。

我真正想写的一直是“邂逅”。两篇小说的开篇都写相遇，一个是一见倾心，一个是久别重逢，这是我潜意识的流露。现实之中难以获得，也不是没获得过，只是又压抑住了而已。暗恋重逢这个主题给开篇的邂逅增加了难度；我现在写的感觉是，理智落后于情感，让他们不断突破边界。“我们不需要回到过去，我们现在就可以重新认识一次。”这是故事里最核心的动作，也是我反复想表达的东西。

我想写一些现代性的文学。他们之所以相互记得对方，是因为没有其他人可以记住。是无数在现实中碰到的失望累积而成。记得最初的人，是一种避免自己心里空洞的自我保护。

“渴望被看见”，是我反复写到的主题。

最初我想写重逢时是欢快的，后来写着写着，环境变热闹了，氛围反而变文艺了。情绪不一定和环境正相关，也可以相反。创作状态和情绪状态密切相关，所以我总觉得自己的创作比较封闭。我总想碰一些更深的主题，却不敢。我的状态和很多没有消化的历史事件有关，写的时候能感觉到它们隐隐约约地影响文本和当下。人在不停地往前走，就会不停地有新的烦恼；旧的烦恼会随着时间扩散，也有很多留在心里。太多现实的烦恼不敢说出来，也不敢写出来，也不相信有人会理解。这个“双向暗恋十年重逢”的设定，其实是在回避那些更深的东西；可我发现，我终究还是需要去写那些原本更适合在“破镜重圆”主题下展开的内容——把情结背后的情绪写进小说里，让男女主互相治愈。我在写的时候也更多地把情感体验注入给女主，以此丰富她的人设形象。

这部半自传体小说，原本就是一个以叙事疗法为基础的叙事重构平台。写作过程渐渐改变了我。我越来越熟练于记录真实而幽微的感受，再把它们放回故事框架里重新驱动。故事设定的治愈感，为许多琐碎的情绪提供了出口。当我越来越敢写现实世界的困惑与困难时，情节开始越来越丰富，越来越充满推动力；而这些自然而然的推动，又反过来启发我在现实世界里积极行动。

起初想写小说，是想试试能不能多一个副业。后来发现小说能写，但要靠它做副业挺困难。因为有现实的压力在，很难全身心探索，会持续感到迷茫和无意义。但“探索”本身正是我的渴望。写作对我更像精神食粮，慢慢就形成了新的动力。

也有过一些具体的设想。我把日常工作中的体悟写进男女主的人设，写出来的初稿可以直接加工用于公司账号。这样就不需要为公司发文单独创作，又可以更隐晦地批评具体对象，同时更直白地表达我们的情绪和感受。以自己的职业生涯为原型来写男女主，原本的意图之一就是让他们在小说世界里继承我的意志。公司名称甚至可以直接用公司的，让小说作为公司宣传和品牌故事的一部分自然呈现。这确实是我原本的创作动机之一，我好像也因此不自觉地找到了更顺畅的创作方式。我发现各种心结都可以借着男女主写出来，因为他们经历的波折是“可迁移的情绪”。设定影响了情节，让情绪可以被重构。越来越多的情绪被装进小说，我开始愿意真正地重构它们、改变它们——也就是真正地忘记它们。

创作还有一个更私人的入口：孤独，谈心，想谈恋爱。有些工作上的烦恼说不出口时，会渴望有一个恋人可以说出口——其实需要的是一个绝对安全的倾诉空间。我甚至知道身心的循环是可以补上的，但很困难。所以我在小说里写了便利店两个人坐着谈心的情节。那个情节已经承载了太多东西，不知道还能写什么。感觉稿子里把常见的情绪都写了一遍，新的情绪和场景又找不到。也试过扩展，写过两个再坐的场景，想象新的情绪，没想象出来，于是只写了脚本。

“瓶子”是一个更早的原型。它来自一个曾经纠缠过的女孩，是她留下的一个印象深刻、也很让人共情的形容。那不算一段愉快的经历，我却始终记得，所以不知道该怎样去写。我选择把这些感受写下来，首先是为了让自己看见它们的形状。我想通过写作让自己释怀。“释怀”是什么？是故事有了不同的意义，而我可以继续向前，而不是像当年的她一样让情绪停留在原地。我看到的是自己也曾经执念过。所以写下这段十年重逢，是希望男女主可以满足他们自己的执念。

这句话好像打开了一扇门，很多积压的情绪从门里涌出来：关于心底里最深处的悸动，关于深刻的被看见和共情，关于这段十年重逢故事里的底色的来源，还有其他爱过的女孩。这些曾经都是故事里男女主们的原型。他们或许比故事里更苦，也在我的愿望里最终更加如愿以偿。这些情绪和男女主的氛围同源。我不敢过多回想，是害怕那些落空的想象会再次让我难过。可大部分其实都已经忘了，留下的印记变成了现在的我。我以为我没有释怀，但事实上已经释怀得差不多了。释怀的是，那些经历最终只是一些故事，它们可以变成男女主相爱的证据——摩擦是真实的摩擦。故事里的一切也都可以改变，我可以在改变的过程中重新发现什么。

我不希望自己的人生状态继续停滞在这里，就像与女主重逢之前的男主一样。我希望祖辈能看到我结婚生子，也希望自己可以实现博士毕业的梦想——不必是经济学，可以是人工智能。这些愿望都可以让男女主们获得。还有更多欲望，关于生活的，关于生命的。害怕死亡，害怕衰老，害怕亲人离世，害怕孤独一人，害怕猝死。是啊，这些都是三十岁的男女主会经历的。真正的“三十而立”就应该是这样，尤其是对那些优秀的社会精英们。这些底色让故事变得真实，让他们面临的挣扎变得真实。我敢写出来吗？又害怕别人知道而伤害自己吗？可能不会吧。

写作也在变成我夜晚的“心力补充站”。每次写完一段给 AI 读完，都会放下焦虑、感到困倦。我渴望写出更具爆发力的片段，直接击中心底的情绪；渴望让那些说不出口的话被说出来，让困扰已久的问题被消解；也渴望多出一些勇气去承载更多的重量，或者学会保持边界。我在无数的怀疑中成长，害怕和恐惧依然很多，我给它们敷上一层薄薄的面纱。白天我很安心，夜晚还是会害怕睡不着；如果白天不安心，又会蔓延到晚上。白天的消化能力总归强一些。直到某一次我把这些写出来，感觉自己找到了现实的出口——虚构世界里的情绪流淌得更自如，反过来又促进现实世界的循环。我常常害怕一切都不会好起来：明明有能力、有服务，却介绍不出去。那是自己的内心在局限自己，是心力不足。所以一到晚上，我就来写作，放下压力和焦虑。

回看这些文字，我看到自己清晰的变化，从困惑逐渐到明晰。写作是一面很好的镜子，我对故事的理解深刻地影响了我对未来的感受。有一段时间心里很安静，很多情绪好久没有来威胁了，反而有点不适应，创作也遇到瓶颈，不知道该怎么把新的状态写进来。想尝试挖掘旧情绪，却找不到合适的入口。尝试写诗歌里的感觉，写不出来，又考虑把它变成一首虚构的歌曲接入剧情。后来，我好像找到了新的创作方式：从情绪日记出发，作为灵感不断重构。

关于故事本身，我也有过一次新的领悟：校园言情本质上是职场言情的 if 线。如果他们二十岁就真的相遇了，会如何呢？按现在流行的写法，可以写重生，但我不太爱这个套路，主线剧情还是先不这么写。写下这些文字的时候，心里又渴望又难过。难过的是，想象自己未来会如何与自己的爱人说起这些过往，甚至怀疑自己配不配爱人。也许很多读者也类似，大家多多少少都经历过许多事情。所以在文字中，我努力保持着对未来的期待，也探索着可能性。

这部小说的隐喻到底是什么？我感觉到自己正在逐渐进入“确定关系”的后半段，这和内心的长久笃定有关。现实世界里，我在一步一步焦急又缓慢地等待事业突破临界点；小说世界里，男女主久别重逢，靠近彼此。我原本以为这部小说会装下我的一生，后来发现，它装下的只是写作这半年的困扰和感受。小说里设定的十年，是我在回顾过去的十年，用的是全新的视角。十年之前意气风发，十年之后无数现实压力困扰着我，就像小说里的男女主一样。这也是我会想到把校园言情作为职场言情 if 线来写的原因：是回到那个时间的渴望。之前的写法是两对人的传承，现在又有了新的想法：干脆用同一对男女主写两本小说，形成真正的 if。未来还可以继续复用形象来写重生剧本。

我时常感觉到幻觉破灭和局限性，但这种感觉恰恰能让我抓住为数不多的优势靠近。就像我一开始想写一个比自己更大的世界，后来发现写的只是自己的切片；写着写着又发现，即使是切片，也已经足够丰富多彩。最近，我又觉得这个虚构世界已经快装不下更多的情绪了，很想写新的东西。很奇妙的是，尝试探索新世界的同时，旧世界反而又有了灵感。每当我动笔，从重生言情总会被拉回职场言情。我想我突破了瓶颈期，写出了一些全新的东西。“校庆”这个片段是我很早就规划过的情节，一直没找到感觉，最近找到了——发现它是一种面对真实困难的现实勇气。这种勇气被带进小说，让男女主角开始写出他们内心真实的感受。

我还想写下心底里的不安，但不知道怎么把它写进去。考虑过写女主遇到困难、男主帮助。如今动笔写得不算多，但一动笔，就觉得自己越来越熟练了。

写作这件事，似乎终究是：把不敢说的，变成可以说的。“我”在这里写出它们，让男女主替我满足执念，替我与生活重新认识一次。
