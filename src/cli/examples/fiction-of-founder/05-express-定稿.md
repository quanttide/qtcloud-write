# 创作动机：把不敢说的，变成可以说的

很多年前，我在心里写下一句话：“我们不需要回到过去，我们现在就可以重新认识一次。”那时并不知道，这句话会成为我后来所有故事的起点。它不是关于写作技巧，而是关于一个人如何面对孤独、恐惧，以及重新认识自己。

最初只是想试试能不能多一个副业。后来发现小说能写，副业却难得多；写作没有变成副业，反而成了精神食粮。现实压力让人无法全身心探索世界，但我更想做一个探索者。许多烦恼不敢说、不敢写，也不相信有人理解，于是渴望一个绝对安全的倾诉空间。孤独、谈心、想谈恋爱，本质上都是对安全空间的渴望——这催生了“便利店两人坐着谈心”的情节。

为什么写小说？因为幻想设定里藏着潜意识。我常常想象意料之外的邂逅，开篇总是一见倾心或久别重逢。这是潜意识的流露：现实中难以获得，或获得过又压抑下去。反复出现的主题，是“渴望被看见”。我选择用男女主角作为展示这种渴望的窗口。写作中，理智常常落后于情感，让人物不断突破边界。

在设定上，我刻意回避“破镜重圆”。我不写十年里他们各自经历了什么，只让重逢带着一种不讲道理的等待。这种等待近乎科幻。双向暗恋、久别重逢是典型母题，但“没有破镜重圆”让故事变得小众。它更甜，也更难写——必须给人物一个合理的动机，而这构成了最大的悬念。直到那句话出现：“我们不需要回到过去，我们现在就可以重新认识一次。”

创作状态与情绪状态密不可分。情绪不一定和环境正相关：想写重逢的欢快，环境却越来越热闹，氛围反而变得文艺。我曾觉得创作封闭，想碰更深的主题却不敢。写不出新情绪时，我尝试从情绪日记出发，作为灵感的起点。从别的方向动笔，总被拉回原来的轨道；突破瓶颈后写出“校庆”片段，带来一种面对真实困难的现实勇气，也让男女主角终于写出内心的真实感受。

这部半自传体小说，本质上是一个叙事重构的平台。当下状态与尚未消化的历史事件有关。我把情结背后的情绪写进小说，让男女主互相治愈。写作让我越来越熟练地记录真实的幽微感受，并在故事框架下重新驱动它们。各种心结可以借着人物写出来，因为他们的波折是可迁移的情绪；设定影响情节，让情绪可以被重构。于是有了两句话：“我愿意真正地重构和改变它了，也就是真正地忘记它们了。”“把不敢说的，变成可以说的。”

小说里的十年，是回顾过去的十年，也是一个全新的视角。十年之前意气风发，十年之后是无数现实压力，就像小说里的男女主。他们三十岁，害怕死亡、衰老、亲人离世、孤独、猝死。真正的三十而立不是什么都拥有，而是带着恐惧一起生活。这些恐惧是故事的底色。校园言情本质上是职场言情的 if 线——如果他们二十岁的年纪真的相遇会如何？这种设想，是回到那个时间的渴望。我用职业生涯作为原型，让男女主在小说世界里继承我的意志。我担心自己配不配爱人，但在文字中保持对未来的期待，探索可能性。

写作和现实形成一个循环：越来越敢写现实世界的困惑时，情节就越来越有推动力；这些推动反过来启发现实中的行动。在虚构世界里情绪流淌得更自如，也促进现实世界的循环。夜晚的焦虑可以在写作中安放。明明有能力却介绍不出去，是内心在局限自己，心力不足；写作成为补充心力的地方。原本以为小说会装下我的一生，后来发现它装下的只是写作这半年的困扰和感受。回看创作谈，看到自己从困惑逐渐走向明晰。写作是一面很好的镜子，对故事的理解深刻影响了对未来的感受。

虚构世界容不下更多情绪时，我想写新东西；而探索新世界，又让旧世界有了灵感。写完一段后放下焦虑、感到困倦；渴望写出更具爆发力的片段，直接击中内心情绪，或让困扰已久的问题被消解。

这就是我们的创作动机。不是逃避现实，而是为了在故事里重新认识一次自己。品牌想做的，就是为那些不敢说、不敢写的情绪，提供一个绝对安全的空间；然后在空间里，长出面对现实的勇气。如果这句话也是你想说的，那我们从这里开始。
